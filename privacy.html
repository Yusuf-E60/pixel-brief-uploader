Privacy Policy

Last updated: November 16, 2026

Who uses this tool

Pixel Brief Uploader is a private desktop tool used only by the channel owner with the owner's own TikTok accounts. It has no public users.

Data the tool handles

When the owner authorizes a TikTok account, the tool receives from TikTok: the account's open ID and display name, and access and refresh tokens. It uses them only to upload the owner's videos to that account as drafts.

Where data is kept

This data is stored only in a local file on the owner's computer. It is not sent to any server other than TikTok's API, not shared with anyone, and not used for advertising or analytics.

Removing access

Access can be removed at any time in the TikTok app under Settings → Security → Manage app permissions, and by deleting the local token file.

This website

This website does not use cookies and does not collect visitor data.
